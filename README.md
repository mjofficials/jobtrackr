# JobTrackr

A full-stack job application tracker with AI-powered features.

## Tech Stack

- **Frontend:** Next.js 14, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** NestJS, Prisma, PostgreSQL (Supabase)
- **AI:** Claude API (Anthropic)
- **Auth:** JWT + Google OAuth

## Projects

- `jobtrackr-api` — NestJS backend
- `jobtrackr-web` — Next.js frontend
